1. What does an HTML table consist of?

An HTML table consists of rows and columns of cells that hold data.

2. Fill in the missing tags.

TagDescription
<table>Defines a table
<thead>Groups header content
<th>Defines a header cell in a table
<tbody>Groups body content
<tr>Defines a row
<td>Defines a table data cell
<caption>Defines a caption for a table

3. Example table code

Take a screenshot of the code below and paste it into question 3 of the worksheet.

<table>
  <caption>Cars I Like</caption>
  <thead>
    <tr>
      <th>Brand</th>
      <th>Model</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ferrari</td>
      <td>812 Superfast</td>
    </tr>
    <tr>
      <td>BMW</td>
      <td>M4</td>
    </tr>
  </tbody>
</table>

4. What tag creates an ordered list?

<ol> creates a numbered list.

5. What tag creates an unordered list?

<ul> creates a bulleted list.

6. What tag creates a list item?

<li> creates an item in either type of list.
